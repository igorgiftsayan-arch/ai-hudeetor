# Глоссарий

| Термин | Значение |
|---|---|
| AI-друг | Персональный AI-компаньон с выбранной персоной; не врач и не медицинский консультант. |
| AI-действие | Пользовательский сценарий, который может резервировать токены и инициировать AI-обработку. |
| Пользовательские токены | Внутренняя единица доступа; не равна токенам AI-провайдера и не является валютой. |
| Резерв | Временное удержание стоимости AI-действия до успеха или технической ошибки. |
| Срыв | Субъективное отклонение пользователя от намеченного поведения; не диагноз. |
| Чек-ин | Структурированная утренняя или вечерняя фиксация состояния. |
| Пополнить токены | Покупка пакета пользовательских токенов на отдельном экране V1; это не добровольный донат без встречного предоставления. |
| Тестовый сервер | Первая общая рабочая среда для проверки проекта. |
| V1 | Зафиксированный объём первой версии согласно [scope-v1.md](scope-v1.md). |
