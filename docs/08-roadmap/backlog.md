# Backlog и открытые решения

## Перед ARCH-001

- Выбрать языки, фреймворки, package/build tooling и структуру пакетов монорепозитория.
- Определить auth/session подход, API style и стратегию миграций.
- Выбрать локальную/test оркестрацию, CI/CD, наблюдаемость и поставщика S3.
- Не выбирать AI-провайдера без отдельного ADR.

## До реализации соответствующих сценариев

- Рефералы: часовой пояс десятидневного окна, перечень учитываемой активности, семантика AI-use.
- Токены: состав полной себестоимости, денежный эквивалент, округление, налоги; классификация бизнес-неуспеха AI.
- Платежи: юридический смысл «доната», поставщик, товары, возвраты и чеки.
- Analytics: словари параметров, ключевое событие retention, исключение тестовых аккаунтов и платформа.
- Privacy/safety: юрисдикции, согласия, сроки хранения, удаление/экспорт, возраст, кризисные сценарии.
- Product: точные поля онбординга/чек-инов, параметры строгости и длины, содержание недельного отчёта и глубокого разбора.

Эти пункты не разрешают добавлять функции за пределами V1.
