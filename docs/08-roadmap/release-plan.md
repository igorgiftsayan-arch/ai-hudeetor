# План релизов

## Этап 0 — Foundation

- DOC-001: документационная основа.
- DOC-002: закрытие архитектурно значимых продуктовых решений.
- ARCH-001: техническая архитектура и ADR без кода.

## Последующие инкременты V1

После BOOT-001 вертикальные задачи идут по областям: идентификация/онбординг; профиль и трекинг; AI-друг и безопасность; токенный кошелёк; питание/меню/списки; feedback/аналитика; рефералы/пополнение; админка/контент; стабилизация и выпуск V1.

Каждый инкремент должен быть вертикально проверяемым и соответствовать [scope-v1.md](../00-product/scope-v1.md). Даты не назначены.
