# План продуктовой аналитики

## Цели

Понять активацию, формирование регулярности, ценность AI-друга, использование сценариев питания, качество ответов, токенную экономику и реферальный рост.

## Принципы

- Единственный перечень имён и параметров — [event-registry.md](event-registry.md).
- Backend — источник событий, связанных с подтверждённым состоянием, деньгами, токенами и наградами.
- Не отправлять свободный текст диалогов, фотографии, точный вес или иные чувствительные данные без отдельного обоснования.
- Использовать псевдонимный `user_id`, `anonymous_id` до регистрации, `event_id`, UTC timestamp и согласованную версию схемы.
- Повторная доставка backend-события дедуплицируется по `event_id`.

Воронки описаны в [funnels.md](funnels.md), формулы — в [metrics.md](metrics.md).
