# Токенная экономика

Пользовательские токены — внутренняя единица продукта и не равны токенам AI-провайдера.

## Начисления и цены

Стартовый баланс — **100 токенов**, начисляется строго один раз на пользователя.

| AI-действие | Цена |
|---|---:|
| Быстрый AI-ответ | 1 |
| Подбор блюда | 3 |
| Разбор продукта | 3 |
| Анализ блюда по фото | 5 |
| Разбор срыва | 5 |
| Меню на день | 10 |
| Недельный отчёт | 15 |
| Глубокий разбор поведения | 20 |

Цены — стартовые значения `AiActionPrice`; они редактируются через админку и не хранятся как константы бизнес-логики. Изменение цены журналируется и влияет только на новые резервы.

## Протокол списания

1. Backend в транзакции читает актуальную цену и резервирует полную стоимость, только если доступного баланса достаточно.
2. При успехе AI-действия резерв подтверждается как расход.
3. При технической ошибке полный резерв возвращается; бизнес-результат «не найдено» должен быть отдельно классифицирован до реализации.
4. Повтор запроса с тем же ключом идемпотентности не создаёт второе списание.

Баланс никогда не отрицательный. Все проводки транзакционны и аудируемы. Ручные начисления требуют администратора, причины и журнала.

## Экономика MVP

Наценка рассчитывается от **полной себестоимости** действия с коэффициентом **1,5**: целевая стоимость = полная себестоимость × 1,5. Состав полной себестоимости, денежный эквивалент токена, округление и налоги — открытые решения; до них формула не задаёт цену пополнения.
