# Соглашения API

- API версионируется явным префиксом (например, `/api/v1`) после выбора стека.
- JSON используется для структурированных запросов и ответов; время — ISO 8601 в UTC, календарная логика учитывает сохранённый часовой пояс пользователя.
- Аутентификация и авторизация проверяются backend на каждом защищённом ресурсе.
- Идентификаторы считаются непрозрачными; клиент не выводит из них права доступа.
- Списки имеют согласованную cursor-based пагинацию, если объём не ограничен контрактом.
- Опасные повторы (платежи, токены, награды, AI-запуски) используют ключ идемпотентности.
- Валидация не раскрывает внутренние детали. Ошибки соответствуют [единому формату](error-format.md).
- Контракты документируются до/вместе с реализацией; каталог маршрутов ведётся в [endpoints.md](endpoints.md).

Frontend не является доверенной границей для цены, баланса, владельца данных или административной роли.
