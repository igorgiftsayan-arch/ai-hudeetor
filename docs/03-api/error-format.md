# Единый формат ошибок API

```json
{
  "error": {
    "code": "INSUFFICIENT_TOKENS",
    "message": "Недостаточно токенов для действия",
    "details": {},
    "request_id": "opaque-request-id"
  }
}
```

## Поля

- `code` — стабильный машинный код.
- `message` — безопасное пользовательское сообщение; локализация решается отдельно.
- `details` — необязательные структурированные данные без секретов и stack trace.
- `request_id` — корреляция с журналами.

HTTP-статус отражает класс ошибки. Ошибки авторизации не подтверждают существование чужого ресурса. Техническая ошибка AI отдельно классифицируется, инициирует возврат резерва и событие `ai_response_error`. Полный словарь кодов будет добавляться вместе с API-контрактами, без изменения оболочки.
