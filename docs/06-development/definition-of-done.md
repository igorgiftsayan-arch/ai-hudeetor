# Definition of Done

Задача завершена только если применимые пункты подтверждены:

- [ ] Код реализован.
- [ ] Миграции созданы, если менялась база.
- [ ] Тесты проходят.
- [ ] API задокументирован.
- [ ] Аналитические события добавлены в реестр и реализацию.
- [ ] Права доступа проверены.
- [ ] Проектная документация обновлена.
- [ ] `docs/08-roadmap/current-status.md` обновлён.
- [ ] `CHANGELOG.md` обновлён.
- [ ] Описан и выполнен сценарий ручной проверки.
- [ ] Функция доступна на тестовом сервере, если задача предполагает выкладку.

Неприменимый пункт должен быть явно отмечен как N/A с причиной; его нельзя молча пропустить. Для документационных задач «код», миграции, API, события и сервер могут быть N/A, но проверка содержания и ссылок обязательна.
