# Тестовый сервер

Первая общая рабочая среда проекта — тестовый сервер. Сейчас он не настроен; его архитектура определена в ARCH-001, а реальный deployment выполняется отдельной задачей.

## Предусмотренные компоненты

- PWA frontend;
- backend API;
- PostgreSQL;
- Redis;
- S3-совместимое хранилище;
- reverse proxy;
- HTTPS;
- защищённые переменные окружения;
- резервное копирование;
- централизованное структурированное логирование;
- smoke test после каждой выкладки.

Среда изолирована от production. Реальные адреса, пароли, ключи и секреты не документируются и не коммитятся; [.env.example](../../.env.example) содержит только имена и фиктивные значения. Архитектура, поставщик и sizing определяются отдельно.
