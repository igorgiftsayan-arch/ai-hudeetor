# Технологический стек

## Зафиксировано DOC-001

| Область | Решение | Статус |
|---|---|---|
| Клиент | PWA frontend | Тип реализации не выбран |
| Сервер | Backend API | Язык и фреймворк не выбраны |
| База данных | PostgreSQL | Зафиксировано |
| Кэш/координация | Redis | Зафиксировано |
| Файлы | S3-совместимое хранилище | Поставщик не выбран |
| Входящий трафик | Reverse proxy + HTTPS | Реализация не выбрана |
| AI | Адаптер внешнего провайдера | Провайдер не выбран |

Конкретные версии, языки, библиотеки, поставщики аналитики, платежей и инфраструктуры выбираются в ARCH-001 или отдельных ADR по критериям поддержки PWA, транзакций, миграций, тестирования, наблюдаемости и эксплуатации на тестовом сервере.
