# ADR-001: монорепозиторий

- Статус: принято
- Дата: 2026-07-18

## Контекст

Frontend, backend, общие контракты, инфраструктура и документация должны изменяться согласованно небольшой командой и последовательными задачами Codex.

## Решение

Использовать один git-репозиторий как источник истины для всех компонентов проекта. Конкретная структура пакетов будет выбрана в ARCH-001.

## Последствия

Единые задачи и атомарные изменения упрощаются; CI должен уметь проверять только затронутые части, а границы компонентов должны оставаться явными. Решение не означает единый runtime или совместное развёртывание.
