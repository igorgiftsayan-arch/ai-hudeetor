# ADR-009: приватное файловое хранилище

- Статус: принято
- Дата: 2026-07-18

## Решение

Пользовательские файлы хранятся только в private S3-compatible storage. PostgreSQL содержит owner, purpose, object key, lifecycle и processing status. Runtime filesystem и репозиторий не являются постоянным хранилищем.

Клиент загружает/читает объект через короткоживущие scoped signed URLs либо защищённый API. Object keys случайны и не содержат PII. Доступ всегда проверяет ownership.

## Upload pipeline

Лимиты размера, MIME allowlist и magic bytes проверяются сервером; EXIF удаляется. Файл находится в quarantine до проверки, затем доступен worker/AI через краткоживущий доступ. Публичные URLs запрещены.

Удаление аккаунта/фото идемпотентно удаляет объект, производные и метаданные; сбой повторяется worker. Lifecycle соответствует privacy policy: исходное фото — не более 30 дней после анализа, либо раньше по запросу.

## Последствия

S3-поставщик, SDK и malware scanner выбираются позже. Профильные фотографии и CDN вне V1.
