# Среды

| Среда | Назначение | Статус |
|---|---|---|
| Локальная | Разработка и автоматические проверки | Будет определена ARCH-001 |
| Test | Первая общая рабочая среда, ручная приёмка и интеграционные проверки | Ещё не настроена |
| Production | Работа реальных пользователей | Вне текущего этапа |

Конфигурация поступает через переменные окружения, секреты не коммитятся. Среды имеют раздельные базы, хранилища, ключи и журналы. Детали тестовой среды — [test-server.md](../07-deployment/test-server.md).
